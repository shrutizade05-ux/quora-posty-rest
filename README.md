# Quora Posty REST API

A Quora-like REST project built using **Node.js and Express.js**.

## Technologies Used

* Node.js
* Express.js
* EJS

## Today's Work

* Created the Express.js server
* Set up the project with Node.js
* Configured EJS as the view engine
* Configured the `views` folder
* Configured the `public` folder for static files
* Added URL-encoded form data support
* Created the basic `/` route
* Started the server using port `8080`

## How to Run

```bash
npm install
node index.js
```

Then open:

```text
http://localhost:8080
```
